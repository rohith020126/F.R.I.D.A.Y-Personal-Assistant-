# F.R.I.D.A.Y-Personal-Assistant-
Friday – Personal Automation Assistant

Friday is a personal automation assistant designed to simplify everyday tasks through natural-language commands. Built with Python, the project combines command processing, browser automation, file handling, and a customized terminal interface to create an interactive assistant experience.

Features

- Website navigation and browser automation.
- Google and YouTube search integration.
- Gemini and ChatGPT search integration.
- Calculator for basic mathematical expressions.
- Personal note management using JSON storage.
- Command history tracking.
- Custom terminal interface with centered text, colors, and status information.
- Error handling for improved reliability.

Technologies Used

- Python
- JSON
- Browser automation
- File handling
- Command-line interface (CLI)

Project Goal

The goal of Friday is to develop a practical personal assistant that can automate repetitive tasks, improve productivity, and provide a foundation for advanced AI-powered and Android-based features.

This project demonstrates skills in Python programming, modular software development, data persistence, user interaction design, and automation.
